## Intro
This repository provides code accompanying the paper "Brief Communications: Tides and Damage as Drivers of Lake
Drainages on Shackleton Ice Shelf" by J. Sommer et al., egusphere-2024-3105, in review at The Cryosphere (2024).


## Install

1. install requirements.txt
pip install -r requirements.txt

2. install setup.py
pip install -e .
